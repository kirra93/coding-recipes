# Project documentation standard seed

This directory is a portable recipe, not a GeekHub API source of truth.

- [English guide](project-documentation-standard.en.md) — recommended canonical
  version for a repository.
- [Русская версия](project-documentation-standard.ru.md) — equivalent reference
  translation.

Copy this directory to a recipes repository or use either guide to bootstrap a
new project. Adapt names, owners, commands, and optional directories to the
project; do not copy example values blindly.

The seed intentionally does not duplicate document templates. A project should
keep its maintained templates in `docs/standards/templates/` as described in the
guide.
