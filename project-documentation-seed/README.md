# Project documentation standard seed

This directory is a portable recipe, not a GeekHub API source of truth.

- [English guide](project-documentation-standard.en.md) — canonical version.
- [Русская версия](project-documentation-standard.ru.md) — reference
  translation; the English version wins on any discrepancy.

Copy this directory to a recipes repository or use either guide to bootstrap a
new project. In a project, install the chosen guide as
`docs/standards/documentation.md`. Adapt names, owners, commands, and optional
directories to the project; do not copy example values blindly.

The seed intentionally does not duplicate document templates. A project should
keep its maintained templates in `docs/standards/templates/` as described in the
guide.
